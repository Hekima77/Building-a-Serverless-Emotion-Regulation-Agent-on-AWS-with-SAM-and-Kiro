TROUBLESHOOTING:
────────────────────────────────────────────────────────────────────────────────

"sam command not found"
   → Download from https://aws.amazon.com/serverless/sam/
   → Restart PowerShell after install

"Access Denied" during deploy
   → Run: aws sts get-caller-identity
   → If fails, run: aws configure
   → Enter your AWS credentials

"ModuleNotFoundError"
   → Make sure you're in the project directory
   → Check __init__.py files exist in src/ and src/services/

"Lambda timeout during execution"
   → Edit template-python.yaml
   → Find "Timeout: 60" and increase the value

════════════════════════════════════════════════════════════════════════════════

WHAT HAPPENS WHEN YOU DEPLOY:
────────────────────────────────────────────────────────────────────────────────

1. SAM packages your Python code
2. Creates Lambda function deployment packages
3. Sets up API Gateway with 2 endpoints:
   - POST /emotion       → Analyze user input & return routine
   - GET /history/{userId} → Retrieve user's interaction history
4. Creates DynamoDB table with TTL (30 day auto-delete)
5. Sets up CloudWatch logging
6. Creates IAM roles with proper permissions

Total time: 5-10 minutes
