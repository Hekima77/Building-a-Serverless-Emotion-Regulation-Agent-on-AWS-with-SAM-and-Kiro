❓ NEED HELP?
────────────────────────────────────────────────────────────────────────────────

"sam: command not found"
   → Download SAM CLI from https://aws.amazon.com/serverless/sam/
   → Restart PowerShell

"Access Denied"
   → Run: aws sts get-caller-identity
   → If fails, run: aws configure (re-enter credentials)

"ModuleNotFoundError"
   → Make sure you're in the right directory
   → Check __init__.py files exist

"Deployment failed"
   → Check AWS Console → CloudFormation
   → Look at Events tab for error details
